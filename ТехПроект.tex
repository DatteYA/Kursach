\section{Технический проект}
\subsection{Общая характеристика организации решения задачи}

Необходимо спроектировать и разработать продукционную систему Маркова, которая моделирует применение правил на входной строке и выводит результаты в графическом интерфейсе.  

Система представляет собой набор взаимосвязанных окон, содержащих:
\begin{itemize}
	\item исходный текст;
	\item правила Маркова (загрузка из файла и ручной ввод);
	\item пошаговое отображение изменений текста;
	\item статистику работы алгоритма;
	\item сохранение журнала выполнения шагов в файл.
\end{itemize}

\subsection{Обоснование выбора технологии проектирования}

На современном рынке программных средств для разработки настольных приложений существует множество инструментов. Для поставленной задачи наилучшим выбором является использование языка Python с библиотекой CustomTkinter для реализации GUI и объектно-ориентированного подхода для построения продукционной системы.

\subsubsection{Описание используемых технологий и языков программирования}

\subsubsection{Язык программирования Python}

Python — высокоуровневый интерпретируемый язык программирования, широко используемый для разработки десктопных и веб-приложений, научных вычислений и машинного обучения.  

\paragraph{Достоинства языка Python}
\begin{itemize}
	\item Простота синтаксиса, быстрый прототипинг.
	\item Кроссплатформенность.
	\item Большое количество библиотек для работы с текстом, GUI и данными.
\end{itemize}

\paragraph{Недостатки языка Python}
\begin{itemize}
	\item Интерпретируемый язык, низкая скорость исполнения по сравнению с C/C++.
	\item Ограниченные возможности для создания нативных GUI без сторонних библиотек.
\end{itemize}

\subsubsection{Библиотека CustomTkinter}

CustomTkinter — расширение стандартной библиотеки Tkinter, позволяющее создавать современные GUI-приложения с темной и светлой темой, а также кастомными элементами управления.

\paragraph{Достоинства CustomTkinter}
\begin{itemize}
	\item Современный внешний вид элементов интерфейса.
	\item Простая интеграция с Python.
	\item Поддержка темной и светлой темы.
\end{itemize}

\paragraph{Недостатки CustomTkinter}
\begin{itemize}
	\item Ограниченная документация по сравнению с Tkinter.
	\item Требует установки дополнительного пакета.
\end{itemize}

\subsection{Диаграмма компонентов и схема обмена данными между файлами компонента}

Диаграмма компонентов отражает архитектуру системы:
\begin{itemize}
	\item GUI-приложение (окна, виджеты);
	\item класс \texttt{MarkovRules} (правила Маркова);
	\item класс \texttt{MarkovSystem} (логика применения правил);
	\item файловая система (хранение правил и журнала).
\end{itemize}
